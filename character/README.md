# GraphQL Character Query by ID

## Objective

This task demonstrates how to query a GraphQL API to retrieve information about a specific character using their unique ID.

## Endpoint

https://rickandmortyapi.com/graphql

## Query Details

The `character(id: ID!)` field is used to fetch a single character.

### Fields Retrieved

- id
- name
- status
- species
- type
- gender

## Characters Queried

- Character ID 1
- Character ID 2
- Character ID 3
- Character ID 4

Each query and its corresponding JSON output is stored in this directory.
